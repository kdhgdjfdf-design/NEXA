# AREA 51 — The White Room

AREA 51 is the new personal learning space built from the NEXA Android project.

## First experience
- **The Room:** a quiet home screen and project launch point.
- **PROJECT 90:** daily learning missions for mathematics, physics, chemistry, and life & earth sciences.
- **Focus Chamber:** a simple local focus timer with 15, 25, and 40 minute sessions.
- **Logbook:** a private on-device error and learning notebook.
- **Initial Assessment:** a short four-subject starter check, designed to grow into a curriculum-aware diagnostic.

## Design principles
- Calm white-room visual language with restrained black and warm-neutral accents.
- Local-first: this prototype stores progress and notes on the device.
- Mastery over hours: the experience encourages understanding and sustainable progress, not excessive study time.
- The existing NEXA main branch is preserved. This prototype lives on `feature/area-51`.

## Build
The Android APK workflow is configured to build this branch on pushes.
